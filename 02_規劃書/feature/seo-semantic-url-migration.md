# 語意化 URL 遷移（P2，未啟動）

依據 2026-09-20 修改報告。不得阻塞 sitemap 診斷。現有 10 位 slug 檢查散布於 sitemap、快照、資料/API 與靜態路由，必須完整盤點。

拆卡每張 2–4 小時，依序執行：
1. S01 唯讀盤點：搜尋 slug validator、查詢、static params、後台欄位；輸出舊新 URL 一對一映射草稿，確認前不更動。
2. S02 資料合約：slug 與 immutable ID 分開、唯一性與 reserved paths、alias 保存規則；先測試，無正式遷移。
3. S03 查詢與路由：相容舊記錄，更新快照/靜態參數/查詢；舊 slug 不直接失效。
4. S04 單一測試服務遷移：preview 301 舊→新、自 canonical、sitemap 與全部內鏈更新；不得建立 redirect chain 或把舊頁導回首頁。
5. S05 擴展與發布：備份、逐筆映射、全站稽核、受控發布與回退；不得批量推導或自動翻譯網址後直接上線。

每張需交付責任檔案清單、負向驗證與回復方式。S01 後依觸及檔案再拆 S02/S03；新增欄位不可讓現有表單或公開內容消失。正式執行前以最新程式重新估工。
