# L22｜相關文章查詢與呈現

## 目標
在文章尾端增加同分類的內部連結，提升閱讀深度與爬蟲發現能力。

## 前置
L08、L20；L21 完成後可改用其列表 helper。

## 修改範圍
只新增相關文章 repository helper、修改文章詳情頁與測試／CSS；不得修改 sitemap 或文章內容。

## 固定規格
最多 3 篇、同 type 同 category、published、排除目前 slug，依發布日期新到舊；不足 3 篇不混入其他分類；無結果時整區隱藏；連結為普通 HTML href。

## 驗收
測試 0、1、3、超過 3 篇、同日期、草稿、不同分類及手機版；SSR HTML 可讀取相關連結，查詢有上限。

## 交接紀錄
記錄 query 條件與 L24 需要抽查的頁面。
