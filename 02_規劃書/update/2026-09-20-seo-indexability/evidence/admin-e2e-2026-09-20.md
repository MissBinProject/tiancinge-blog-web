# 管理後台本機 E2E 驗證（2026-09-20）

## 執行範圍

以本機 fixture 登入模式驗證後台 UI 與文章／服務／留言／素材操作；不連線正式 Firestore，也不使用正式管理員密碼。測試環境使用 `VITE_ADMIN_AUTH_SERVER=false`，測試程序以一次性環境變數提供測試密碼，沒有把密碼寫入文件或 log。

## 命令與結果

```sh
E2E_ADMIN_PASSWORD=<test-only-value> \
  pnpm exec playwright test e2e/admin.spec.ts e2e/username-login.spec.ts --workers=1
```

- 21 tests passed。
- 覆蓋文章清單／編輯／草稿、服務新增、留言備註與狀態、分類限制、文章格式工具列、YouTube 插入、拖曳圖片、封面上傳與封面選擇視窗、手機版無水平溢出、登入失敗與登出。
- 上述結果證明目前前端互動契約與 fixture 流程一致；不代表正式帳號、正式 API、正式 Storage 的授權 E2E 已完成。

## 後續

正式管理員帳號 E2E 仍需由維運者在受控環境提供一次性測試憑證，完成後不得將憑證寫入 repository 或證據文件。
