# C04 sitemap 收錄範圍清理

狀態：已完成並通過整合驗收。優先級：P1。預估：2–3 小時。

## 輸入與依賴

B01、C03。先讀本目錄 README 共同規則；以實際上一張交付為準，不假設依賴已完成。

## 責任範圍

apps/sitemap-worker/src/document.mjs；document.test.mjs。

## 工作步驟

依逐頁表移除 privacy/terms 的 sitemap 列項；保留頁面、頁尾連結與目前索引設定。空分類排除；薄分類先用明確名單排除，保留實際可用內容頁；不自動排除所有短服務頁。

## 驗收

輸出前後 URL 差異及逐頁理由；不含草稿、redirect、noindex；不新增 priority/changefreq；不得將 sitemap 排除等同 robots 封鎖。

## 交付與邊界

提交修改差異（純稽核卡交付 evidence 文件）、實際驗證命令/結果、殘留風險。測試僅針對本卡；日期/收錄規則使用不同輸入與負向案例。內容卡以人工逐頁校閱驗收；未完成不得標記完成。不得自行遷移網址、全站 noindex 或越過 F01/F02 發布；不得覆蓋其他任務的變更。
