# B01 全站可索引性稽核工具

狀態：已完成。優先級：P0。預估：3–4 小時。

## 輸入與依賴

A01。先讀本目錄 README 共同規則；以實際上一張交付為準，不假設依賴已完成。

## 責任範圍

scripts/verify-sitemap.py 或新增 scripts/audit-indexability.py。

## 工作步驟

從 sitemap 及同源 a[href] 收集路由，另比對靜態輸出路由；輸出 CSV/JSON：URL、來源、status、redirect、meta/X-Robots-Tag、robots 允許、canonical、title、description、H1 數量文字、正文量、內鏈數、result。正文排除導覽頁尾。

## 驗收

抓到 sitemap 外的孤立頁線索；重複 title/description 分組；HTTP 404 與 soft-404 候選分開，正文短不能自動判 soft-404；不執行 JS 也能檢查主要正文。

## 交付與邊界

提交修改差異（純稽核卡交付 evidence 文件）、實際驗證命令/結果、殘留風險。測試僅針對本卡；日期/收錄規則使用不同輸入與負向案例。內容卡以人工逐頁校閱驗收；未完成不得標記完成。不得自行遷移網址、全站 noindex 或越過 F01/F02 發布；不得覆蓋其他任務的變更。

交付：`scripts/audit-indexability.mjs` 與 `pnpm seo:audit`。正式網站最後一次驗證 17 個 sitemap route 全部 HTTP 200、self-canonical、唯一 title/description、單一 H1、無 noindex，並檢查內部 HTML 連結。
