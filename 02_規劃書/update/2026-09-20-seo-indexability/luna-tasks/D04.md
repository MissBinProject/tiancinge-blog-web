# D04 確認內容匯入與薄分類處理

狀態：待店家確認內容後執行。優先級：P1。預估：2–4 小時。

## 輸入與依賴

C04、D01、D03 確認後。先讀本目錄 README 共同規則；以實際上一張交付為準，不假設依賴已完成。

## 責任範圍

既有後台內容管理流程；分類 page.tsx／metadata（如確定採 noindex）。

## 工作步驟

先備份目標公開內容，再用既有後台/API 按 ID 匯入確認內容；最多一個內容批次。分類若採 noindex，統一其分頁與 sitemap，允許爬蟲讀取 noindex。

## 驗收

輸出修改 ID/欄位、不含個資；價格電話待確認不發布；自動靜態重建後 HTML 可見；每筆可回復；內容太多時按服務與文章再拆兩批。

## 交付與邊界

提交修改差異（純稽核卡交付 evidence 文件）、實際驗證命令/結果、殘留風險。測試僅針對本卡；日期/收錄規則使用不同輸入與負向案例。內容卡以人工逐頁校閱驗收；未完成不得標記完成。不得自行遷移網址、全站 noindex 或越過 F01/F02 發布；不得覆蓋其他任務的變更。
