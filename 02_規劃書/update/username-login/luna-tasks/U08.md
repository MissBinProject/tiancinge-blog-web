# U08 帳號密碼重設 use case

- 狀態：待執行。
- 目標：帳號密碼重設 use case。
- 參考：../修改程式規劃書.md；目前後台登入卡片（無新設計稿）。
- 前置：U02,U03。
- 可修改範圍：application/accountLogin.ts、對應測試。
- 固定資料契約：主規劃第 4 節；帳號 tiancinge 對應既有 Firebase Email，保留 UID、密碼與權限。跨卡契約若需修改，先更新規劃與依賴卡，不能各自更名。
- 操作步驟：帳號對應恢復 Email，呼叫既有重設 adapter；未知帳號同一中性回應。
- 驗收方式：有效帳號送往固定映射；未知帳號不寄信且不洩漏存在狀態。
- 驗證門檻：程式卡執行 admin typecheck、相關測試；階段結束執行 admin build。文件卡檢查連結與 git diff --check；部署卡核對線上結果。
- 範圍限制：不更動官網、Rules、其他管理頁；不把 fixture 通過視為 Firebase 整合通過；不保存密碼。
- 預估工時：1–2 小時。
