# 正式 Firebase 驗收操作

此文件只記錄操作方式，不記錄密碼、驗證 token 或信件內容。

## 登入驗收

1. 開啟 https://tiancinge-admin.web.app/。
2. 在「管理員帳號」輸入 `tiancinge`，輸入管理員目前密碼後登入。
3. 確認進入「總覽」，並可讀取管理員允許的資料。
4. 登出後以不存在的帳號測試，確認只顯示一般錯誤訊息。

## 重設密碼驗收

1. 在登入頁輸入 `tiancinge`，按「忘記密碼？寄送重設信件」。
2. 到管理員綁定信箱開啟 Firebase 重設信件，依 hosted action handler 設定新密碼。
3. 回到登入頁，以新密碼登入並確認進入「總覽」。
4. 確認舊密碼無法登入；不要將密碼或信件內容寫入測試報告。
