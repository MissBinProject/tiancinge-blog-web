# Luna 任務卡使用方式

每張卡只負責一個可驗收結果，控制在一個模組或一個雲端操作範圍，通常不超過 1–4 小時、6 個主要檔案；需要帳號持有人或 GCP 權限的步驟會明確標成外部前置條件。Luna 執行時應先閱讀本資料夾上層的 `data-contract.md` 與 `validation-checklist.md`，不得重設或覆蓋其他未提交修改；完成後回報修改檔案、測試指令、結果與未解風險。

建議依序執行未完成項目：`S05（註冊）→ S06 → S12 → S14（enforce）→ S16 → S17 → S18`。S01–S04、S07–S11、S13、S15 及 S14 report-only 已由本次執行完成，保留各卡作為回歸驗收規格。
