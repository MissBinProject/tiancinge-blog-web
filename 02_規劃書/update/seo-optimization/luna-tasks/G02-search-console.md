# G02｜Google Search Console

## 目標
由具備網域或 URL-prefix 權限的人完成驗證並提交 sitemap。

## 前置
正式網站已部署，`https://tiancinge-web.web.app/sitemap.xml` HTTP 200，且帳號持有人可登入 Search Console。

## 步驟
1. 建立 URL-prefix property `https://tiancinge-web.web.app/`。
2. 使用 HTML meta、HTML file、DNS 或既有 Google Analytics 其中一種可核實方式驗證。
3. 在 Sitemaps 提交 `sitemap.xml`，記錄狀態與時間。

## 驗收證據
Search Console property verification 與 sitemap submission 已有文字紀錄，詳見 `../../2026-09-20-seo-indexability/evidence/a02-gsc-followup-2026-09-20.md`；Google 仍顯示「無法擷取」時，標記為外部待處理，不得宣稱已收錄或保證排名。

## 交接
提供提交日期、帳號角色、sitemap 狀態與後續第 7/28 天檢查日期，不在文件中保存登入資訊。
