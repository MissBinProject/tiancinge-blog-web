# UI/UX 計畫

- 桌機基準依 1672px 設計稿，使用 Noto Serif TC／Noto Sans TC 與粉玫瑰色系。
- 導覽固定於頂端，區段錨點扣除導覽高度；手機改為抽屜選單。
- 背景採提供的主視覺、服務價格、最新消息、部落格及聯絡素材。
- 卡片、表單、按鈕提供 hover、focus、送出中、成功、錯誤與空資料狀態。
- 手機檢查 390px 與 768px，禁止水平溢出；缺少手機設計稿時沿用相同視覺變數重新排版。

## 響應式配置矩陣

以下是沒有手機原稿時的第一版實作基準；`推定` 項目需在店家提供手機稿後再做疊圖確認。

| 區段 | 1672／桌機 | 768／平板 | 390／手機 | 圖片與溢出規則 |
|---|---|---|---|---|
| 固定導覽 | Logo、六個錨點、社群、搜尋及 LINE 按鈕同列 | Logo、預約、選單按鈕 | Logo、預約、44px 選單按鈕；連結改抽屜 | `position: fixed`；內容 `scroll-margin-top` 扣除導覽高度 |
| 主視覺 | 背景滿版，品牌文案與直排裝飾 | 背景 cover，文案縮小 | 單欄文案、按鈕滿寬，隱藏非必要直排裝飾（推定） | `object-fit: cover`／背景 `center`；不得產生水平捲軸 |
| 服務 | 五欄卡片、卡片照片 285×125 | 三欄卡片 | 單欄卡片 | 卡片圖片固定比例 `object-fit: cover`，長服務名稱可換行 |
| 價格 | 五欄卡片與四筆特色列 | 三欄後續列（推定） | 單欄價格卡、特色列改單欄（推定） | 價格與服務共用資料；洽詢價格不顯示數字 |
| 最新消息 | 三卡手動輪播、箭頭與圓點 | 三卡縮窄 | 一卡一頁、箭頭／圓點 44px | 不自動播放；內容不足時隱藏控制 |
| 部落格 | 四欄卡片、五個分類入口 | 兩欄卡片 | 單欄卡片、分類可換行 | 卡片圖片 `object-fit: cover`；分類入口可觸控 |
| 聯繫資訊 | 左文案／表單，右地圖／QR／社群 | 改上下排列（推定） | 表單、地圖、QR 依序單欄 | iframe、QR 最大寬度 100%；表單欄位不超出容器 |
| 頁尾 | 品牌、導覽、版權同列 | 品牌與導覽換行 | 品牌、導覽、版權分列 | 文字可換行；不使用固定寬度造成溢出 |
| 列表／詳情／搜尋 | 內頁 banner、四欄列表／雙欄詳情 | 兩欄列表／單欄詳情（推定） | 單欄列表／詳情 | 分頁與分類連結最小觸控尺寸 44px |

## 觸控與狀態基準

- 主要按鈕、手機選單、輪播箭頭、分類與分頁連結至少 44×44px。
- 所有表單提供 idle、sending、success、error；失敗時保留使用者已輸入內容。
- 空列表、缺圖、載入中及錯誤狀態保留容器高度，不讓版面突然跳動。
- 驗證寬度為 390、768、1440、1672px；每個寬度都必須通過 `document.documentElement.scrollWidth <= clientWidth`。
