# Luna 任務卡

每張卡只修改一個功能切片，完成後附上變更檔案、驗收截圖、測試命令及交接備註。任務依 `A 規格素材 → B 基礎資料 → C 官網 → D 後台 → E 串接上線` 執行。

## 任務卡索引

- A01–A07：設計素材對照、裁切、設計變數、頁面樣板及共享契約。
- B01–B10：workspace、fixture、Supabase migration／RLS、資料 adapter。
- C01–C18：首頁各區、內頁、搜尋、政策與手機版。
- D01–D17：登入、固定版型內容、服務、文章、素材、留言與設定。
- E01–E11：正式資料、留言串接、SEO、疊圖驗收、部署與備份。

## 任務卡格式

各卡以所屬群組檔案開頭的設計圖／素材路徑作為參考圖；`步驟` 是操作步驟，`驗收` 行末的 `交接：` 是交接紀錄。每張卡的實際日期、命令、證據、提交 SHA 與待辦狀態集中在 [`commit-map.md`](./commit-map.md)；正式環境卡片完成後，再於該表補上 deployment／Supabase project、URL、截圖位置、結果與已知差異。

```md
# [ID] 任務名稱
目標：
參考圖：
前置任務：
允許修改：
固定契約：
操作步驟：
驗收：
交接紀錄：
```
