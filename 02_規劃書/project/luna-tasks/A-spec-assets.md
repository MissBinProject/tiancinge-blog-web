# A 規格與素材基線任務卡

每張卡由 Luna 單獨完成；參考圖均位於 `03_UI設計圖/01_首頁設計圖`，素材位於 `03_UI設計圖/02_素材`。完成後在交接欄填入提交、截圖及差異。

## A01 建立設計圖與素材對照表
- 參考圖：`03_UI設計圖/01_首頁設計圖/`；素材：`03_UI設計圖/02_素材/`。
- 目標：列出五張設計圖尺寸、區段、用途、素材對應與缺件。
- 前置任務：無。允許修改：`03_UI設計圖/asset-map.md`。
- 固定契約：輸出欄位為 `source、size、section、asset、missing、note`。
- 步驟：檢查原圖尺寸 → 以檔名建立對應 → 標記無原始照片、字型及手機稿。
- 驗收：五張圖及長圖均有紀錄，缺件可追溯；交接：附 `asset-map.md` 及檢查命令。

- 交接紀錄：完成後記錄執行日期、操作者、命令或 URL、截圖位置、結果與已知差異。

## A02 定義裁切座標與素材匯出流程
- 參考圖：`03_UI設計圖/01_首頁設計圖/`；素材：`03_UI設計圖/02_素材/`。
- 目標：以非破壞方式產生服務、消息及部落格卡片裁切圖。
- 前置任務：A01。允許修改：`apps/web/public/assets/crops/`、裁切說明。
- 固定契約：檔名 `service-{1..5}.png`、`news-{1..3}.png`、`blog-{1..4}.png`。
- 步驟：記錄原圖座標 → 使用 `sips` 或等效流程輸出 → 記錄尺寸與來源。
- 驗收：可重複執行且不覆蓋原始檔；交接：附座標表、輸出尺寸及差異。

- 交接紀錄：完成後記錄執行日期、操作者、命令或 URL、截圖位置、結果與已知差異。

## A03 處理 Logo、背景、裝飾及照片
- 參考圖：`03_UI設計圖/01_首頁設計圖/`；素材：`03_UI設計圖/02_素材/`。
- 目標：整理可供網站直接引用的 PNG/JPEG/WebP 素材。
- 前置任務：A01、A02。允許修改：`apps/web/public/assets/`、素材索引。
- 固定契約：圖片 MIME 僅 JPEG、PNG、WebP；單檔不得超過 10 MB。
- 步驟：複製原素材 → 清理檔名及路徑 → 檢查透明度、尺寸、清晰度。
- 驗收：Logo、四個背景、聯絡背景與裁切卡均可載入；交接：附清單及失真註記。

- 交接紀錄：完成後記錄執行日期、操作者、命令或 URL、截圖位置、結果與已知差異。

## A04 比對字型與建立設計變數
- 參考圖：`03_UI設計圖/01_首頁設計圖/`；素材：`03_UI設計圖/02_素材/`。
- 目標：固定色碼、字級、行高、間距、圓角、陰影及版心。
- 前置任務：A03。允許修改：`apps/web/src/app/globals.css`、`apps/admin/src/styles.css`、設計文件。

- 驗收：1440 px 截圖可重現 token，字型差異列入清單；交接：附 token 表及截圖。

- 交接紀錄：完成後記錄執行日期、操作者、命令或 URL、截圖位置、結果與已知差異。

## A05 建立手機版配置規格
- 參考圖：`03_UI設計圖/01_首頁設計圖/`；素材：`03_UI設計圖/02_素材/`。
- 目標：定義 390、768 px 的導覽、區塊、卡片、背景裁切及表單排列。
- 前置任務：A04。允許修改：`02_規劃書/project/ui-ux-plan.md`、手機規格文件。

- 驗收：每一區有配置表及未知項目；交接：附尺寸矩陣。

- 交接紀錄：完成後記錄執行日期、操作者、命令或 URL、截圖位置、結果與已知差異。
