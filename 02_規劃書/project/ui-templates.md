# 內頁與後台樣板

這份樣板給沒有原始設計稿的服務內頁、文章內頁、搜尋頁與後台畫面使用。版型固定，內容由 repository 提供；所有樣板都必須有載入、空資料、錯誤與成功回饋。

## 公開頁樣板

| 樣板 | 結構 | 可變內容 | 狀態 |
|---|---|---|---|
| 列表 | `Header → inner-hero → category-filters → card-grid → pagination → Footer` | banner 標題、副標題、分類、卡片 | 載入、無結果、分頁超出時回到最後一頁 |
| 詳情 | `Header → cover → metadata → title/excerpt → ArticleBody → Footer` | 封面、分類、日期、結構化正文 | 未發布或 slug 不存在回 404；正文 block 無效時不渲染 |
| 服務詳情 | `Header → detail image → summary → description → duration/price → LINE CTA → Footer` | 服務圖片、介紹、分鐘數、價格 | 隱藏服務與不存在 slug 回 404；洽詢價格顯示聯繫 CTA |
| 搜尋 | `Header → search form → result count → result list → pagination → Footer` | 關鍵字與公開結果 | 空查詢、無結果、網路錯誤都有文字回饋 |

列表卡固定包含圖片、分類／日期、標題、摘要及「閱讀更多／了解更多」連結；圖片一律使用 `SafeImage`，失效時保留替代文字與固定比例。

## 後台樣板

```text
┌─────────────────────────────────────────────────────┐
│ 固定側欄（總覽／服務／文章／素材／留言／設定）      │
├───────────────┬─────────────────────────────────────┤
│ 篩選／資料列   │ 編輯表單                           │
│ 分頁／空狀態   │ 儲存、預覽、刪除與狀態回饋          │
└───────────────┴─────────────────────────────────────┘
```

| 模組 | 左側清單 | 右側表單 | 必備狀態 |
|---|---|---|---|
| 服務價格 | 依 `sortOrder` 排序、上架／隱藏 | 內容、圖片、分鐘數、價格／洽詢 | 載入、空列表、資料載入錯誤、驗證錯誤、儲存成功／失敗 |
| 文章／分類 | 類型、狀態、關鍵字、分頁 | 基本資料、封面、正文 block、預覽 | 草稿、發布、預覽、正文驗證、未儲存提醒 |
| 素材 | 關鍵字、MIME 篩選、尺寸 | 上傳、替代文字、刪除確認 | 檔案限制、上傳中、失敗、使用中不可刪 |
| 留言 | 未處理／已處理、分頁 | 內容、內部備註、處理／刪除 | 空列表、資料載入錯誤、備註保存、刪除確認、錯誤 |
| 設定 | — | 聯絡、社群、SEO、政策、首頁區塊 | 欄位驗證、背景／圖片選擇、同步提示 |

## 共用元件與資料界線

- 公開頁只呼叫 `loadServices`、`loadArticles`、`loadSettings` 等公開 repository；不在 component 內寫 Supabase 查詢。
- 後台表單只透過 `apps/admin/src/repositories.ts` 寫入；素材選擇器回傳 `id、url、alt`，不直接處理 Storage 權限。
- `ArticleBody` 只接受 `heading、paragraph、list、link、image`，先通過共用 validator 才渲染。
- 表單儲存後顯示成功訊息；失敗保留輸入並顯示原因；離頁或切換資料列時攔截未儲存變更。
