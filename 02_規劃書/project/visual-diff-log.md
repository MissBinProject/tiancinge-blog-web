## 基準

- 桌機設計稿：`03_UI設計圖/01_首頁設計圖/首頁_01.png` 至 `首頁_05.png`，每張 1672 × 941。
- 目前瀏覽器：本機 Next.js dev server，內容使用 fixture；`capture-visual.mjs` 會在截圖前等待字型並注入停用 animation／transition 的樣式，`devIndicators` 已關閉，避免開發浮標污染像素比對。
- 手機基準：390、768 px；目前以 CSS 重排，原始手機稿尚未提供。

## 本機基準截圖

執行 `pnpm visual:capture` 會以 1672 × 941 的 Chrome viewport 產生下列目前版本截圖，供逐區疊圖及回歸比對；再執行 `pnpm visual:diff` 會產生同尺寸 overlay 與 difference 圖：

- `02_規劃書/project/visual-baseline/current-01.png`：導覽、主視覺、服務
- `02_規劃書/project/visual-baseline/current-02.png`：價格
- `02_規劃書/project/visual-baseline/current-03.png`：最新消息
- `02_規劃書/project/visual-baseline/current-04.png`：部落格
- `02_規劃書/project/visual-baseline/current-05.png`：聯繫與頁尾
- `02_規劃書/project/visual-baseline/overlay-01..05.png`：設計稿與目前截圖的 50/50 疊圖
- `02_規劃書/project/visual-baseline/difference-01..05.png`：像素差異定位圖

服務區目前預設使用 CSS 裝飾背景。原始 `首頁_01.png` 是包含導覽、主視覺及服務文字的完整畫面，直接作為背景會重複繪製內容，因此保留為設計參考並避免在區塊內重複顯示。

1672px 主視覺與服務區已依 `首頁_01.png` 將區段邊界固定為 470／471px，服務卡群對齊原稿左右基準，主視覺補回左側英文、中央手寫提示及右側蓮花直排裝飾；價格區已依 `首頁_02.png` 將卡片群移至右側基準線，補回五組服務圖示、左側直排、右上／右下手寫及底部英文裝飾，並調整標題垂直位置、圖片高度、卡片內距、特色列高度與區段邊界；最新消息與部落格卡片、分類列、聯繫頁表單／地圖／社群欄及頁尾版心也已依 `首頁_03.png`～`首頁_05.png` 校正，聯繫區補回左側英文蓮花、中央手寫提示及右側直排標語裝飾。更新後仍需以店家提供的原始字型與照片完成最後疊圖確認。

主視覺預設標題使用現有 `天心閣_原色去背.png` 去背字樣，提升原稿字形的一致性；後台自訂主標題時改用文字，避免固定素材阻斷內容編輯。

## 尚待正式疊圖修正

目前 overlay／difference 已依本機 fixture 產生，供差異定位使用。店家確認正式字型、電話／地址／價格、原始卡片照片後，需重新執行 `pnpm visual:capture && pnpm visual:diff` 並記錄修正；現有卡片照片由設計稿裁切，不能視為原始素材的一模一樣替代品。

消息／部落格區另補回原稿左右直排、手寫文案、底部英文與「查看更多」入口；暫用裁切圖含有原稿內嵌分類標籤，首頁卡片以裁切容器與 live badge 對齊處理，避免標籤重疊。
